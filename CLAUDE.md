# CLAUDE.md

Учебный проект курса (Design + Code), отдельный от TEFS-практики. Plain HTML/CSS/JS, без сборки и пакетного менеджера.

- Entry point: [index.html](index.html)
- Styles: [styles.css](styles.css)
- Behavior: [script.js](script.js)
- Static assets: `assets/img/`

Дев-сервера и билд-шага нет — открывать [index.html](index.html) напрямую в браузере (или через простой статик-сервер / Live Server).
